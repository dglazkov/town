# Projects

One directory per body of work. A project holds everything about itself:
the ideal it is aiming at (`journey.md`), the mechanism (`design.md`), and
the walk that gets there (`phases.md`). Reading a project end to end is
`ls` and then reading in order; adding a doc to one edits nothing outside
it.

**Where each project stands lives in its own primary doc**, in front
matter, so this table cannot be more right than the thing it describes.

**Each phase has a `**Status:**` line, and its word is one of four:**
`NOT STARTED`, `PART-DONE`, `CLOSED`, or `WITHDRAWN`, followed by the date
it last moved and one sentence of what holds. A newly planned project's
phases are all `**Status: NOT STARTED.**`; never `OPEN`, which the
conductor's status script does not know. The words are defined in
[`/conduct`](../../.claude/skills/conduct/SKILL.md), and
`.claude/skills/conduct/status.sh <project>` lints them.

**A project is short.** It holds one body of work with an end: a journey
that can be walked, phases that close, a last phase after which nothing
in it waits on work. A project that turns out to be long-lived was cut at
the wrong grain and should have been several. The pilot in the draft
([../drafts/town-design-doc.md](../drafts/town-design-doc.md) §16) is
several such projects, each named for what it adds to the town.

| [gate](gate/) | The town's gate: where a grant is checked. One server on one box, a grant file in an agent's directory, the `town` command as a thin client and `townd` as the operator's, help rendered on the server for the calling grant, a call allowed or denied before any shop runs, and one shop, `town/memory`, built from a manifest and run as a subprocess. No credentials, no Square, no Town Hall: the operator puts shops and grants in at the box. [`design.md`](gate/design.md) is the argument, [`journey.md`](gate/journey.md) the acceptance suite, [`phases.md`](gate/phases.md) the walk. | **Done 12 Sep 2026.** All three phases closed. The town runs on one laptop: manifest, runtime, `town/memory`, the store, the gate, help for the grant, the audit, the admin, and `town` as a pipe. It was walked by a real Claude Code session: no call denied, and after its grant was narrowed it said it could no longer write memory. Nothing waits. |
| [vault](vault/) | The town's vault: where a credential is kept and used on a shop's behalf without the shop ever holding it. Typed credentials seeded with a GitHub token, the operator connecting one from stdin, rows sealed under a key file, a binding made with the grant, and the teller: a loopback window opened per call that signs a shop's requests to the type's origin and closes after. One new shop, `town/github`. No OAuth, no Square, no egress control. [`design.md`](vault/design.md) is the argument, [`journey.md`](vault/journey.md) the acceptance suite, [`phases.md`](vault/phases.md) the walk. | **Done 12 Sep 2026.** All three phases closed. Credentials are sealed under `vault.key`, bound to grants, opened only when a call is allowed, and signed onto the wire by a per-call teller. `town/github` was walked by a real Claude Code session on a real token: no call denied, the reply on GitHub, and after narrowing it said it could no longer reply; the token was in no file searched. Open, owed to a containers project: on one box a shop can read the key and unseal. |
| [compose](compose/) | The town's compose: where a shop calls other shops through the town as the agent that called it, and never as more. One new shop, `town/watch`, a recipe over `town/github` and `town/memory`. No private needs, no Town Hall, no containers. [`design.md`](compose/design.md) is the argument, [`journey.md`](compose/journey.md) the acceptance suite, [`phases.md`](compose/phases.md) the walk. | **Done 12 Sep 2026.** All three phases closed. Nothing waits. |
| [hall](hall/) | The town's hall: where an agent finds, writes, publishes, and asks for shops. Town Hall as `town/hall`, a shop the town is born with whose commands run in the town's process, granted and narrowed like any other; a shop sent on stdin as a tar, validated against the spec, tested with the agent's own grants, kept under the user's name, and held by the publishing pass alone; and a permit, a grant an agent proposes and the operator approves, as asked or narrower, or denies. No second user, no credentials at a sent shop, no Square, no containers. [`design.md`](hall/design.md) is the argument, [`journey.md`](hall/journey.md) the acceptance suite, [`phases.md`](hall/phases.md) the walk. | **Done 12 Sep 2026.** A real Claude Code session read the hall's help and spec, wrote a to-do shop, got it through `validate` on the third try (both refusals §2), published it, and used it. Asked for what its grant did not allow, it asked with `request`, and did it once the operator approved. The token was in no file searched but the grant file. Next is [wall](wall/). |
| [wall](wall/) | The town's wall: where a shop's process is enclosed. The runtime contract of spec §7 made a mechanism: a shop reads its own directory, reads and writes its state, reaches the tellers and the clerk the town opened for the call, and nothing else on the box, not the data directory, not the key, not the operator's home, not the network, not the town itself. Seatbelt on this Mac behind a seam the Linux box will fill, `--wall none` to run unwalled and say so, the audit's `wall` column, and vault's exfil test turned around. The project earlier docs call containers. [`design.md`](wall/design.md) is the argument, [`journey.md`](wall/journey.md) the acceptance suite, [`phases.md`](wall/phases.md) the walk. | **Done 12 Sep 2026.** `townd serve` walls every shop by Seatbelt on this Mac unless `--wall none` is written, and refuses a box without a wall; the audit has a `wall` column, and vault's exfil test reads `EPERM` for the key. A real Claude Code session wrote a shop that pried, published it, and ran it walled: its report named its own directory and state readable and the town's files, the home, and the network refused, and asked for a page's title, it said its shops cannot reach the web. The token was in no file searched but the grant file. Next is [consent](consent/). |
| [consent](consent/) | The town's consent: where a credential the town has never seen enters it. The walk, consent phase 2, waits on a provider token from the shepherd (⚑). |
